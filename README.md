# אתר בית ספרי

אתר סטטי בעברית (RTL) לשמירת קודים מהשיעורים ולניהול לוח שאלות ותשובות.
הכול רץ בדפדפן — קובץ `index.html` יחיד, בלי שרת, בלי תלויות חיצוניות.

## מה יש באתר

**חשבונות**
- הרשמה והתחברות, עם שמירת החיבור בין רענוני דף.
- סיסמאות נשמרות כגיבוב SHA-256 עם מלח אקראי לכל משתמש (2000 סבבים) — לא כטקסט גלוי.
- חשבונות שנוצרו בגרסה הישנה (סיסמה גלויה) ממשיכים לעבוד, ומשודרגים לגיבוב בהתחברות הראשונה.

**הקודים שלי** — פרטי לכל משתמש
- שמירת קוד עם שם תרגיל ובחירת שפה (Java / HTML / טקסט, או זיהוי אוטומטי).
- הדגשת תחביר ל-Java ול-HTML.
- עריכה, מחיקה, העתקה ללוח, וחיפוש לפי שם תרגיל או תוכן הקוד.
- כל משתמש רואה ומוחק רק את הקודים שלו.

**שאלות ותשובות** — לוח משותף
- כל משתמש יכול לפרסם שאלה ולענות על שאלות של אחרים.
- כל תשובה מציגה מי כתב אותה ומתי.
- מחיקה מוגבלת לבעלים: שאלה נמחקת רק על ידי מי ששאל, תשובה רק על ידי מי שענה.
- חיפוש בשאלות ובתשובות, וסינון "רק השאלות שלי".

**כללי**
- מצב כהה ובהיר, עם זיהוי העדפת המערכת ושמירת הבחירה.
- מותאם לנייד מרוחב 320px ומעלה.
- כל טקסט שמשתמש מזין מוצג כטקסט בלבד (`textContent`), כך שאי אפשר להזריק HTML דרך שם תרגיל, שאלה או קוד.

## הרצה

אין שלב בנייה. אפשר לפתוח את `index.html` ישירות בדפדפן, או להגיש את התיקייה:

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

## אחסון

הנתונים נשמרים ב-`localStorage` של הדפדפן ולא נשלחים לשום שרת. המפתחות:
`users`, `savedCodes`, `questions`, `loggedInUser`, `theme`.

מכיוון שהכול מקומי, המשמעות היא שהנתונים נשארים על המכשיר הזה בלבד, ושמי שיש לו גישה
לדפדפן יכול לקרוא אותם. ההפרדה בין משתמשים כאן היא הפרדה לוגית בתוך הדף, לא אבטחה מול
תוקף עם גישה למכשיר.
